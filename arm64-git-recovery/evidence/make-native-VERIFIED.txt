VERIFICATION (same standard as the GCC stand-up — file inspection alone is insufficient on this host):
  1. RAW COFF machine of mingw32-make.exe = 0xAA64 (read from PE header offset e_lfanew+4). MEASURED.
  2. IsWow64Process2 on the LIVE make process: processMachine=0x0000 (IMAGE_FILE_MACHINE_UNKNOWN = NOT
     under WOW64 = genuinely native), nativeMachine=0xAA64. An x64-emulated make would report 0x8664.
     MEASURED on the running process, not inferred from the file.
  3. REAL WORK (not just --version): drove a Makefile that invoked our WoA gcc to compile+link app.c;
     the produced app.exe was 0xAA64 and RAN, returning the distinctive value 99. make exit 0.
     => native ARM64 make + native ARM64 WoA gcc together perform a real build on-host.
